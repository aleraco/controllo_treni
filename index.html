Cosa fa la skill

Capostazione virtuale è una skill Alexa indipendente che fornisce aggiornamenti in tempo reale sui treni regionali italiani (orario, binario, ritardo), utilizzando il servizio pubblico ViaggiaTreno di Trenitalia/RFI. La skill non è un prodotto ufficiale di Trenitalia o RFI.

Dati raccolti

Capostazione virtuale non raccoglie, non memorizza e non condivide alcun dato personale dell'utente. Le uniche informazioni scambiate durante una richiesta sono i nomi delle stazioni e l'orario pronunciati dall'utente, usati esclusivamente per formulare la richiesta al servizio ViaggiaTreno e generare la risposta vocale. Questi dati non vengono salvati dopo la risposta e non vengono associati in alcun modo all'identità dell'utente.

Permessi richiesti

La skill non richiede alcun permesso Alexa: nessun accesso a indirizzo, contatti, cronologia acquisti, account linking o dati del profilo Amazon.

Servizi di terze parti

Per rispondere alle richieste, la skill interroga le API pubbliche di ViaggiaTreno (Trenitalia/RFI). Non abbiamo alcuna affiliazione con Trenitalia o RFI. Per l'elaborazione delle richieste vocali si applica inoltre l'informativa privacy di Amazon Alexa, consultabile su amazon.it.

Log tecnici

La skill è ospitata su infrastruttura Amazon Web Services (AWS Lambda). Per finalità di diagnostica tecnica, AWS può conservare log tecnici temporanei relativi alle richieste elaborate, secondo le policy standard di Amazon Web Services, indipendentemente dalla volontà dello sviluppatore della skill.
